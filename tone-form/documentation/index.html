Overview

TONE / FORM Template Documentation

A luxury beauty-tech commercial HTML5 template engineered specifically for complexion cosmetics, shade discovery algorithms, and internal inventory management.

Brand Tagline: "Your Shade. Your Match. Your Finish."
Brand Personality: Minimalist luxury, editorial precision, inclusive depth architecture, non-medical beauty guidance.
Foundation

2. Technology Stack

Constructed strictly without heavy JavaScript single-page application frameworks to ensure instant loading, full SEO discoverability, and simple customization:

Bootstrap 5.3.3
Responsive grid system, modals, dropdowns, and accessible flexbox containers.
Vanilla CSS3 & CSS Variables
Bespoke design system featuring warm ivory surfaces, deep espresso typography, and dark mode tokens.
Vanilla JavaScript (ES6+)
Modular functions driving shade swatch selection, wizard navigation, quiz scoring, and real-time total calculations.
GSAP 3.12.5
Subtle, non-disruptive entrance animations respecting prefers-reduced-motion.

Files & Layouts

4. Compact Page Structure

  • index.html: Editorial beauty-tech homepage with hero match card, undertone preview, kit highlight, and photo reviews.
  • shop.html: Product catalogue with category filters, finish/undertone filters, and quick-view modal.
  • product-details.html: Full PDP with multi-angle gallery, interactive shade selector, and 7-tier shade table.
  • shade-match.html: 5-step interactive complexion wizard calculating custom foundation and sister concealer matches.
  • undertone-analyzer.html: Educational optical quiz analyzing vein, jewelry, and contrast cues.
  • kit-builder.html: 4-step custom base builder with live pricing calculation and bundle discount.
  • reviews.html: Customer photo review masonry gallery with depth filters and review submission modal.
  • dashboard/*.html: Internal inventory management overview, stock ledger, low-stock alerts, and SKU analytics.
JavaScript Functionality

5. Interactive Engines

All front-end demo behaviors are implemented in clean, vanilla JavaScript inside assets/js/main.js:

• initNavbar(): Scroll detection and escape key closing
• initShadeSwatches(): Live swatch selection and label synchronization
• initShadeMatcherWizard(): 5-step wizard state machine with confidence score
• initUndertoneAnalyzer(): Quiz score tallying and educational profile outputs
• initKitBuilder(): Persistent state calculation with 15% discount math
• initDashboardEngine(): Client-side inventory search, filtering, and restock modal

7. Accessibility & Motion

Complies with WCAG guidelines: ARIA labels on all swatch chips, focus rings on all interactive elements, keyboard-accessible modals, and full support for @media (prefers-reduced-motion: reduce).

Developer Notes

8. Customization Guide

To customize shades, edit the shadeDatabase object in assets/js/main.js. To modify brand colors, update the CSS variables in assets/css/style.css.
